# XiaoConvert V2 - Fitur 1 Kompres Gambar REAL

## SETUP PROFESIONAL
1. npm install
2. npm run dev
3. buka http://localhost:3000

## DEPLOY KE VERCEL
- npx vercel --prod
- atau drag folder ke vercel dashboard

## FITUR REAL
- Kompres gambar 100% di browser (Canvas API)
- Quality 10-100% real ngaruh ke size
- Resize Max W/H
- Ganti format: ORIGINAL / JPG / PNG / WEBP / AVIF
- Preview KB + % saved real
- Batch 20 file
- 100% offline, file ga pernah upload

## STACK
Next.js 14 + TypeScript + Tailwind
No database, no VPS, no API berbayar
